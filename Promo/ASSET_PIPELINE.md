# AI素材パイプライン：メッシュとリギング

Star Catcher で使っている「AIで作った3Dモデルを、ゲームで使える形にする」手順です。
すべて無料枠と無料ツールの範囲で動きます。

## 全体の流れ

```
文章（プロンプト）
  └─ Meshy text-to-3D（preview → refine）        Promo/tools/meshy_gen.py
       ├─ 人型キャラ → Meshy 自動リギング            Promo/tools/meshy_rig.py
       │     24本の骨＋歩き・走りアニメーション付きFBX
       └─ 小物（星・爆弾）→ メッシュ最適化           Promo/tools/mesh_optimize.py
             テクスチャを保ったまま約80%軽量化（OBJ）
  └─ Unity 取り込み（自動）                          Assets/Editor/BuildScript.cs
       PrepareModels：FBXに埋め込まれたテクスチャを取り出す
       PrepareRig   ：Legacyアニメーションとして取り込み、ループ設定
  └─ ゲーム内で動かす                                Assets/Scripts/GameManager.cs
```

## 1. メッシュ（形）の作り方

| 方法 | 向いているもの | 今回 |
|---|---|---|
| Meshy text-to-3D | キャラ・小物を文章から作る | ✅ 使用（1体 約2分・30クレジット） |
| `mesh_optimize.py`（pymeshlab） | 大量に出す小物の軽量化 | ✅ 星 8,289→1,499 / 爆弾 7,706→1,500 三角形 |
| Meshy Remesh API | トポロジー作り直し・ポリゴン数調整 | 有料クレジットが必要なので未使用 |
| Blender（無料） | 手作業の修正・細かい調整 | 未インストール（必要になったら導入） |

`mesh_optimize.py` がやること：
- テクスチャ座標（UV）を保ったまま、ポリゴン数を目標値まで削減（Quadric Edge Collapse）
- 中心（ピボット）を原点に、最大辺を1に正規化 → Unity側で大きさをそろえやすい
- 重複頂点の削除

```
python Promo/tools/mesh_optimize.py <input.glb> <出力フォルダ> <名前> <目標三角形数>
```

## 2. リギング（骨組み）の作り方

| 対象 | 方法 | 今回 |
|---|---|---|
| 人型キャラ（2足歩行） | **Meshy 自動リギング API**（5クレジット） | ✅ プレイヤーのロボット：24本の骨、歩き・走りアニメ付き |
| 人型キャラ（別案） | Mixamo（無料・Webで手動アップロード） | 予備案 |
| 人型でないもの（星・爆弾など） | **骨を使わないプロシージャルアニメーション**（コードで動かす） | ✅ 星は脈打つ／爆弾は地面に近づくほど速く揺れて膨らむ |
| 複雑な非人型（動物・乗り物など） | Blender で骨を手付け＋自動ウェイト | 必要になったら |

```
python Promo/tools/meshy_rig.py <Meshyのrefineタスクid> <出力フォルダ> [身長m]
```

注意点（Meshy 自動リギング）：
- 人型・テクスチャ付き・正面が +Z 向きのモデルのみ
- 38万三角形まで
- 走りアニメには「前に進む動き（ルートモーション）」が入っているため、
  ゲームでは腰（Hips）の水平位置を毎フレーム固定して、その場で走らせている

## 3. ゲーム内での動かし方（GameManager.cs）

- 走っているとき：`run` アニメ（移動の強さで再生速度を変える）＋進行方向へ体を向ける
- 止まっているとき：カメラの方を向いて、待機ポーズ＋小さな「呼吸」の動き
- 爆弾に当たったとき：つぶれて戻る（スクワッシュ＆ストレッチ）リアクション
- 3Dモデルがない場合は、自動で2Dの図形に切り替わる
